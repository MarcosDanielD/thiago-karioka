# Tiago Karioka · Educador Físico & Nutricionista

Landing page profissional desenvolvida para Tiago Karioka, unindo Educação Física e Nutrição com foco em reeducação alimentar, emagrecimento saudável e ganho de massa muscular.

## ✨ Recursos

- **Design System Editorial:** Inspirado no guia de estilo Grove AI (`DESIGN.md`), com estética clínica e refinada, tipografia contrastante (Libre Caslon Text + Geist) e paleta monocromática com acento verde floresta (`#0b835c`).
- **Intro Screen Animada:** Abertura suave com contagem e revelação fluida.
- **Scroll & Interatividade:** Barra de progresso no topo, revelação escalonada de elementos ao rolar (IntersectionObserver), efeito sutil de profundidade nas imagens e marquee contínuo.
- **100% Responsivo:** Otimizado meticulosamente para dispositivos móveis, com menu em tela cheia e botão de ação rápido (CTA) fixo.
- **Performance:** Construído em HTML5, CSS3 puro e JavaScript vanilla, sem frameworks pesados ou dependências externas além das fontes Google.

## 🚀 Como Visualizar

Basta abrir o arquivo `index.html` em qualquer navegador web moderno.
